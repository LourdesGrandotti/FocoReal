# 🎯 FocoReal

**FocoReal** es una app de escritorio para ayudarte a mantener la concentración mientras trabajás o estudiás. Te hace chequeos aleatorios de foco, registra tus distracciones y te manda mensajes motivacionales para que no bajes los brazos.

---

## ✨ Funcionalidades

- ▶️ **Control de sesión** — Iniciá, pausá, reanudá y detené tu sesión de trabajo
- ⏱️ **Timer en tiempo real** — Ve cuánto tiempo llevás trabajando
- 🔔 **Chequeos aleatorios** — Cada 60 a 90 segundos te pregunta si seguís concentrado
- 📊 **Contador de distracciones** — Registra cuántas veces te distrajiste
- 📝 **Historial con timestamps** — Ver el registro completo de tu sesión
- 💬 **Mensajes motivacionales** — Se rotan cada 5 segundos para mantenerte enfocado
- 💾 **Guardado automático en Excel** — Al finalizar cada sesión guarda fecha, duración y distracciones en `historial_foco.xlsx`
